# Prototipo

`demo.html` es la demo funcional de Plancito: un solo archivo HTML que se abre en el navegador del celular o la computadora. Simula el registro, la verificación, las invitaciones con garantía, el link de invitación, la cita doble, el Jueves de Plancito, el check-in y la calificación. Guarda el estado en el navegador (localStorage); no cobra dinero ni usa cámara o ubicación.

Sirve como referencia de pantallas y flujo para construir la app real en `app/`.
