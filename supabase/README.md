# supabase/

Aquí van las tablas, reglas de seguridad (RLS) y funciones del servidor de Plancito: perfiles, invitaciones, citas, garantías, reportes y chat. Se empieza en la fase 2 del plan.

Regla: ninguna foto de INE ni dato de tarjeta se guarda aquí; viven en el proveedor de verificación y en el procesador de pagos.
